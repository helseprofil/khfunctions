KHfunctions er hovedhjernen til dataprosessering for folkehelseprofilene. 

Hovedfunksjoner:
- LagFilgruppe() - stabler originalfiler og formatterer kolonner for videre prosessering
- LagKUBE() - lager ferdige filer for publikasjon

For at funksjonene skal fungere er man også avhengig av tilhørende Access-database. 
Konfigurasjon gjøres i [backend-prosjektet](https://github.com/helseprofil/backend) på GitHub, hvor også spesialsnutter leses fra.
